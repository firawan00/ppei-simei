==Pengajuan Rencana Diklat==
Karyawan-->Sistem HCDP:Mengajukan draft perencanaan diklat (Print dokumen)
Sistem HCDP->Database HCDP: Insert data perencanaan diklat dengan status draft
Database HCDP-->Sistem HCDP: Insert data sukses
Sistem HCDP-->Karyawan: Notifikasi sistem sukses
Sistem HCDP->Karyawan: Notifikasi draft perencanaan diklat yang sedang berjalan
Karyawan->Admin Unit Kerja: Permohonan approval dokumen fisik
Admin Unit Kerja->Karyawan: Approval dokumen fisik
Karyawan->Sistem HCDP: Upload dokumen approval ke draft perencanaan
Sistem HCDP->Database HCDP:Ubah status dokumen perencanaan diklat dari draft ke pending_approval_unit
Database HCDP->Sistem HCDP: Sukses ubah status
Sistem HCDP->Karyawan: Notifikasi insert approval sukses
Sistem HCDP->Admin Unit Kerja:Notifikasi pending approval perencanaan diklat
Admin Unit Kerja->Sistem HCDP:Approval pengajuan perencanaan diklat
Sistem HCDP->Database HCDP:Ubah status dokumen perencanaan dari pending approval ke pending_approval_kepegawaian
Database HCDP->Sistem HCDP:Insert sukses
Admin Unit Kerja-->Sistem HCDP:Mengajukan perencanaan diklat
Sistem HCDP->Database HCDP:Insert data perencanaan diklat dengan status pending_approval_kepegawaian
Sistem HCDP-->Admin Unit Kerja: Sukses input perencanaan diklat
Sistem HCDP->Admin Unit Kerja:Notifikasi sukses insert data
Sistem HCDP->Admin HCDP:Notifikasi pending approval
Admin HCDP->Sistem HCDP:Approval perencanaan diklat
Sistem HCDP->Database HCDP:Ubah status dokumen perencanaan diklat dari pending approval kepegawaian ke approved
Sistem HCDP-->Karyawan:Notifikasi perencanaan diklat approved
Sistem HCDP->Admin HCDP:Request approval perencanaan diklat
Admin HCDP->Sistem HCDP:Approval perencanaan diklat
Sistem HCDP->Database HCDP:Insert data approval perencanaan diklat
Sistem HCDP-->Admin Unit Kerja: Notifikasi approval perencanaan diklat
Sistem HCDP->Karyawan: Notifikasi approval perencanaan diklat
Admin Unit Kerja->Sistem HCDP:Lihat reporting perencanaan diklat
Admin HCDP->Sistem HCDP:Lihat reporting perencanaan diklat

==Pelaksanaan Diklat==
Sistem HCDP-->Karyawan: Notifikasi pelaksanaan diklat
Karyawan->Sistem HCDP: Isi form pelaksanaan diklat
Sistem HCDP->Database HCDP:Insert data pelaksanaan diklat
Sistem HCDP->Simpeg: Integrasi data pelaksanaan diklat
Admin Unit Kerja->Sistem HCDP:Lihat reporting pelaksanaan diklat
Admin HCDP->Sistem HCDP:Lihat reporting pelaksanaan diklat

==Evaluasi Diklat==
Sistem HCDP-->Karyawan: Notifikasi evaluasi diklat
Karyawan->Sistem HCDP:Isi form evaluasi diklat (Print dan butuh approval fisik upload)
Sistem HCDP->Database HCDP:Insert data evaluasi diklat
Sistem HCDP->Simpeg: Integrasi data evaluasi diklat
Admin Unit Kerja->Sistem HCDP:Lihat reporting pelaksanaan diklat
Admin HCDP->Sistem HCDP:Lihat reporting pelaksanaan diklat
